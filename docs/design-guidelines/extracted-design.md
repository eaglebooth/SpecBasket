# SpecBasket visual direction
User supplied logo copied unchanged to frontend/public/logo.png. Logo has dark navy
structure, electric blue, green signals and purple document tabs. Use a warm paper
research workspace, navy text, blue primary actions, green supported and amber
uncertainty. Logo is a brand asset, not a screenshot layout to reproduce.
Large editorial serif headings, readable sans body, monospace transaction IDs.
Requirement rows and a source-by-requirement matrix are the primary composition.
No nested scrollbars. Responsive cards collapse to a single column. Visible focus,
labels, reduced-motion support. No fake contract address or simulated results.
