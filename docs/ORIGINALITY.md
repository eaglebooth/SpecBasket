# Material architectural distinction

| Dimension | Earlier mechanism | SpecBasket |
|---|---|---|
| TermHarbor | semantic old/new policy delta -> compensation pool | requirement/source relation matrix -> bounded matching |
| StateLoom | layout lineage and one-use activation capability | multi-requirement coverage allocation, no implementation activation |
| ForkLens | real diff/test/CI facts -> upgrade gate | published specification propositions only; no CI/runtime claim |
| ScopeMutex | overlap with held work -> exclusive round right | simultaneous source/requirement assignment; no work locks or epochs |
| Core verification | consumer revision or held assignment | independently re-derived complete source rows and grounded quotes |
| Consequence | activation/compensation/work capability | canonical research collection and exact optional GEN transfer outbox |

Erase brand/nouns: this remains a bounded bipartite assignment over independently
established semantic edges, with deterministic maximum coverage and tied payout.
No previous contract state machine or frontend layout is copied. Security patterns
(sender auth, commitments, readback and append-only receipts) are intentionally reused.
